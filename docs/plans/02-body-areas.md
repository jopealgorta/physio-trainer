# Spec 02 · Body areas: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** One canonical list of body areas and sides (Postgres enums, TS arrays, zod schemas,
translations) plus a reusable `BodyAreaPicker` (SVG body map + accessible list) and a
`BodyAreaBadge`, viewable on a dev-only preview page.

**Architecture:** `src/lib/body-areas.ts` is the single source: `const` arrays, types, zod
schemas and the pure selection reducers (`toggleArea`, `selectArea`, `coversRegion`). The
Drizzle `pgEnum`s are built from those arrays. The picker is a client component that keeps map
and list in sync through the reducers and renders hidden inputs so it works inside a native
`<form>`. Map geometry is data (`body-map-regions.ts`), drawn by a small `BodyMap` component.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind v4, shadcn/ui (Radix), next-intl 4,
Drizzle ORM (pgEnum), zod v4, Vitest + Testing Library, local Supabase for the integration test.

**Spec:** [`docs/specs/02-body-areas.md`](../specs/02-body-areas.md) (read it and
[`docs/architecture.md`](../architecture.md) before starting).

## Review Focus

Failure modes the spec implies that would bite a real physio; each has a test in the named task.

1. **Clicking the same paired region repeatedly** (left knee, right knee, left knee again,
   right knee again) must cycle left → both → right → cleared, never get stuck or leave a stale
   side. → Task 1 reducer table.
2. **Mirroring on the front view**: the patient's left knee is on the viewer's _right_ on the
   front view and on the viewer's left on the back view. Getting this backwards records the
   wrong side of an injury. → Task 3 geometry test.
3. **Switching area after choosing a side** (knee·left → neck, or via the list) must drop the
   side: the side group disappears and the hidden side input submits `""`. → Task 4 test.
4. **Stray form fields**: Radix checkbox/radio internals rendered inside a `<form>` must not add
   fields to `FormData`; only `name`/`sideName` appear. → Task 4 test.
5. **Controlled usage**: with `value` + `onChange`, the picker reports the next value and shows
   exactly what the parent passes (a parent that ignores `onChange` keeps the old selection). →
   Task 4 test.

import { z } from "zod";

/**
 * Canonical body areas (spec 02), head to toe. Single source for the Postgres enum
 * (src/db/schema/enums.ts), zod, translations (BodyAreas.areas.*) and the picker.
 * Adding a value needs a migration; removing one is hard, so treat this list as append-only.
 */
export const BODY_AREAS = [
  "head_jaw",
  "neck",
  "shoulder",
  "upper_back",
  "chest",
  "upper_arm",
  "elbow",
  "forearm_wrist_hand",
  "lower_back",
  "abdomen_core",
  "hip_groin",
  "glute",
  "thigh",
  "knee",
  "lower_leg",
  "ankle_foot",
  "full_body",
] as const;
export type BodyArea = (typeof BODY_AREAS)[number];

export const BODY_SIDES = ["left", "right", "both"] as const;
export type BodySide = (typeof BODY_SIDES)[number];

/** The side a single map region stands for. */
export type RegionSide = Exclude<BodySide, "both">;

/** Areas drawn once per side on the body map. Everything else is midline. */
export const PAIRED_BODY_AREAS = [
  "shoulder",
  "upper_arm",
  "elbow",
  "forearm_wrist_hand",
  "hip_groin",
  "glute",
  "thigh",
  "knee",
  "lower_leg",
  "ankle_foot",
] as const satisfies readonly BodyArea[];

export const bodyAreaSchema = z.enum(BODY_AREAS);
export const bodySideSchema = z.enum(BODY_SIDES);

/** Injury cases (spec 04) record one concrete area: full_body only makes sense for exercises. */
export const caseBodyAreaSchema = bodyAreaSchema.exclude(["full_body"]);
export type CaseBodyArea = z.infer<typeof caseBodyAreaSchema>;
export const CASE_BODY_AREAS = caseBodyAreaSchema.options;

export function isPairedArea(area: BodyArea): boolean {
  return (PAIRED_BODY_AREAS as readonly BodyArea[]).includes(area);
}

/** Single-mode picker value. `side` is null for midline areas or when no side was chosen. */
export type BodyAreaSelection = { area: BodyArea; side: BodySide | null };

/** Multi mode: add or remove `area`, returning a new array in canonical order. */
export function toggleArea(value: readonly BodyArea[], area: BodyArea): BodyArea[] {
  const next = new Set(value);
  if (next.has(area)) next.delete(area);
  else next.add(area);
  return BODY_AREAS.filter((candidate) => next.has(candidate));
}

const otherSide = (side: RegionSide): RegionSide => (side === "left" ? "right" : "left");

/**
 * Single mode: the value after clicking a map region or choosing an area in the list.
 * `clicked` is the region's side (null for midline regions and list choices).
 * With sides, clicking both sides of a paired area gives "both"; clicking the only chosen side
 * again clears the selection, and clicking a selected midline area again clears it too.
 */
export function selectArea(
  value: BodyAreaSelection | null,
  area: BodyArea,
  clicked: RegionSide | null,
  withSide: boolean,
): BodyAreaSelection | null {
  const side = withSide && isPairedArea(area) ? clicked : null;
  if (value?.area !== area) return { area, side };
  if (side === null) return null;
  if (value.side === null) return { area, side };
  if (value.side === side) return null;
  if (value.side === "both") return { area, side: otherSide(side) };
  return { area, side: "both" };
}

/** Whether a map region is highlighted for a single-mode value. */
export function coversRegion(
  value: BodyAreaSelection | null,
  area: BodyArea,
  regionSide: RegionSide | null,
): boolean {
  if (value?.area !== area) return false;
  return (
    regionSide === null || value.side === null || value.side === "both" || value.side === regionSide
  );
}
```

  id: string;

  area: BodyArea;
  side: RegionSide | null;

  x,

  height,
  radius,

function useControllable<T>(
  value: T | undefined,
  defaultValue: T,
  onChange?: (value: T) => void,
): [T, (next: T) => void] {
  const [inner, setInner] = useState(defaultValue);
  const controlled = value !== undefined;
  const current = controlled ? value : inner;
  const set = (next: T) => {
    if (!controlled) setInner(next);
    onChange?.(next);
  };
  return [current, set];
}

function PickerLayout({

  children,

  onChange,
  name,
  label,
  className,

        ))}

  withSide = false,
  name,
  sideName = name ? `${name}Side` : undefined,
  label,
  className,

  const t = useTranslations("BodyAreas");
  const id = useId();
  const [selection, setSelection] = useControllable(value, defaultValue, onChange);
  const legend = label ?? t("picker.areaLabel");
  const showSide = withSide && selection !== null && isPairedArea(selection.area);

  return (
    <PickerLayout
      legend={legend}
      className={className}
      renderMap={(view) => (
        <BodyMap
          view={view}
          isSelected={(region) => coversRegion(selection, region.area, region.side)}
          onRegionClick={(region) =>
            setSelection(selectArea(selection, region.area, region.side, withSide))
          }
        />
      )}
    >
      <RadioGroup
        aria-label={legend}
        value={selection?.area ?? ""}
        onValueChange={(area) =>
          setSelection(selectArea(selection, area as BodyArea, null, withSide))
        }
        className={LIST_CLASS}
      >
        {CASE_BODY_AREAS.map((area) => (
          <div key={area} className="flex items-center gap-2">
            <RadioGroupItem id={`${id}-${area}`} value={area} />
            <Label htmlFor={`${id}-${area}`}>{t(`areas.${area}`)}</Label>
          </div>
        ))}
      </RadioGroup>
      {showSide && (
        <div className="flex flex-col gap-2">
          <span id={`${id}-side`} className="text-sm font-medium">
            {t("picker.sideLabel")}
          </span>
          <RadioGroup
            aria-labelledby={`${id}-side`}
            value={selection.side ?? ""}
            onValueChange={(side) => setSelection({ area: selection.area, side: side as BodySide })}
            className="flex gap-4"
          >
            {BODY_SIDES.map((side) => (
              <div key={side} className="flex items-center gap-2">
                <RadioGroupItem id={`${id}-side-${side}`} value={side} />
                <Label htmlFor={`${id}-side-${side}`}>{t(`sides.${side}`)}</Label>
              </div>
            ))}
          </RadioGroup>
        </div>
      )}
      {selection && (
        <Button
          type="button"
          variant="ghost"
          size="sm"
          className="self-start"
          onClick={() => setSelection(null)}
        >
          {t("picker.clear")}
        </Button>
      )}
      {name && <input type="hidden" name={name} value={selection?.area ?? ""} />}
      {withSide && sideName && (
        <input type="hidden" name={sideName} value={selection?.side ?? ""} />
      )}
    </PickerLayout>
  );
}
```

Note: `aria-labelledby` makes the side group's accessible name "Side", matching the test's
